# ADR 0001: Use C++17

## Status

Accepted.

## Context

LX targets current Ubuntu and Debian releases as well as Rocky, RHEL, and
AlmaLinux 8/9. The codebase needs a stable standard supported across those
environments.

## Decision

Production code uses standard C++17 with compiler extensions disabled. C++20
library and language facilities are not used unless a future ADR raises the
project baseline.

## Consequences

The project provides its own small `Result` abstraction and uses fmt where
C++17 lacks standard formatting. GCC and Clang remain first-class compilers.
